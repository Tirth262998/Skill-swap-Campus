# SkillSwap Campus frontend

Frontend-only Week 1 visual preview for SkillSwap Campus. This folder uses React, JavaScript (JSX), and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Current routes

- `/` — landing page
- `/register` — registration form preview
- `/login` — login form preview
- `/dashboard` — dashboard shell preview
- `/profile` — profile contract-pending screen

Authentication and profile submission are intentionally not connected. No mock authentication, API endpoints, request bodies, or successful responses are implemented. The fields on the registration and login screens are disabled visual examples, not a confirmed backend request schema. See [docs/week1-api-handoff.md](./docs/week1-api-handoff.md) for backend teammate actions.
